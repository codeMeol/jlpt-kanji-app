# JLPT 한자 회상·쓰기 — 제품·수익화 로드맵

작성 기준일: 2026-09-18

이 문서는 현재 저장소에 실제로 구현된 구조와 목표 구조의 차이를
고정하고, 다음 작업자가 우선순위를 바꾸거나 완료되지 않은 기능을 완료로
오인하지 않도록 한다.

## 1. 제품 정의

### 핵심 사용자

- 시험 1~3개월 전의 한국인 JLPT 수험생
- 종이와 펜으로 한자를 직접 써 보며 외우려는 사용자
- 복잡한 덱 설정이나 과도한 게임화보다 5~10분의 짧은 복습을 원하는 사용자

### 핵심 약속

> 화면에는 한자만 보여 준다. 사용자가 종이에 써 본 뒤 탭하면 뜻과 읽기가
> 나타나고, 틀린 한자는 적절한 시점에 다시 나온다.

앱 자체 필기 판정 기능이 없는 동안에는 스토어 설명에 "종이에 직접 써 본
뒤 확인하는 학습법"이라고 명시한다.

## 2. 현재 구조와 목표 구조 비교

| 영역 | 현재 구현 | 목표 구조 | 차이/위험 |
|---|---|---|---|
| 앱 셸 | Flutter 네이티브 홈·학습·시험 | 그대로 유지 | 적합 |
| 카드 앞면 | 글꼴로 200px 한자 표시 | 캐시된 PenX 한자 이미지, 실패 시 텍스트 | 이미지 URL이 현재 미사용 |
| 답 공개 | 탭으로 뜻·음독·훈독 표시 | 구조화 데이터로 즉시 공개 | 기본 동작은 적합 |
| 상세 설명 | 없음 | 두 번째 동작으로 PenX 상세 WebView | `card_html.dart`와 패키지는 있으나 흐름 미연결 |
| 페이지 이동 | 네이티브 이전·다음·셔플 | 네이티브 유지 | 적합 |
| 콘텐츠 소스 | 내장 N5 103자 우선; 빌드 상수 존재 시 PenX 우선 | 발행된 PenX API + 버전 캐시 + 내장 fallback | 기본 릴리스에서는 PenX가 비활성일 수 있음 |
| PenX 파싱 | 제목/Markdown 정규식 | 버전이 있는 구조화 JSON 계약 | 현재 파싱은 형식 변경에 취약 |
| 로컬 상태 | 마지막 위치, 암기 ID, 최고점 | 모름/애매/암기, 복습 예정일, 이력·진도 | 유지율 기능 부족 |
| 시험 | 무작위 10문제, 한자→뜻 4지선다 | 뜻·읽기·역방향·오답·급수 모의시험 | 한 유형만 제공 |
| 오프라인 | 내장 데이터로 시작 가능 | 이미지·게시물 캐시까지 오프라인 | 원격 자산 캐시 없음 |
| 분석 | 없음 | 최소 퍼널 이벤트 또는 익명 집계 | 수익 판단 근거 없음 |
| 과금 | 없음 | N5 무료 + Pro/급수팩 영구 구매 | Billing·구매복원 미구현 |
| 보안 | signing properties가 Git 추적 대상 | Secret/로컬 파일만 사용 | 즉시 처리할 P0 위험 |
| 문서 | README와 실제 렌더러가 불일치 | 코드·파이프라인·상태 일치 | 인수인계 오류 가능 |

## 3. 설계 결론

완전한 WebView 앱이나 완전한 로컬 앱 중 하나를 선택하지 않는다.

```text
PenX 관리자 작성
  -> 발행된 구조화 카드 API
  -> 앱 로컬 캐시
  -> 네이티브 이미지 앞면
  -> 네이티브 답 공개/진도/시험
  -> 선택 시에만 상세 WebView
  -> 실패 시 내장 N5 JSON
```

WebView는 관리자가 만든 긴 설명을 재사용하는 보조 화면이다. 시작 화면,
학습 진행, 정답 공개, 시험, 결제의 필수 경로가 WebView에 의존하면 안 된다.

## 4. 우선순위 로드맵

### P0 — 릴리스 무결성·보안

목적: 현재 산출물을 신뢰할 수 있고 다음 변경이 안전한 상태를 만든다.

- [ ] `android/keystore.properties`를 Git 추적에서 제거하고 ignore 규칙 확인
- [ ] 원격 Git 기록의 비밀 노출 범위를 확인하고 키/비밀번호 회전 필요성 판단
- [ ] 다른 앱과 업로드 키를 공유했는지 확인
- [ ] `aab.zip`, `android/build/` 등 생성물 정리 및 ignore 보강
- [ ] JLPT 앱 전용 개인정보처리방침 공개 URL 준비
- [ ] 앱 내 KANJIDIC2 출처·CC BY-SA·비공식 급수 고지 연결
- [ ] 실제 release APK의 시작·학습·시험·재시작·오프라인 회귀 검증
- [ ] ARTEMIS의 Google 모델 인증과 ADB device 연결을 완료하고 release trace 보존
- [ ] README, 파이프라인, 체크포인트를 실제 구현과 일치시킴

완료 기준:

- 저장소와 GitHub Actions에 평문 signing secret이 없다.
- 서명된 release APK가 실제 기기 또는 에뮬레이터에서 핵심 시나리오를 통과한다.
- 직접 ADB 결과와 ARTEMIS AI 결과가 분리 기록되고, ARTEMIS 완료 주장에는 trace가 있다.
- 개인정보처리방침과 라이선스 페이지가 외부 HTTPS 200으로 접근된다.

### P1 — 카드 콘텐츠 파이프라인 정상화

목적: 원래 의도한 이미지 중심 학습과 PenX 운영을 실제 제품에 연결한다.

- [ ] PenX 카드 API 스키마에 `id`, `kanji`, `level`, `meaningKo`, 읽기,
      획수, `imageUrl`, `detailUrl`, `contentVersion`, `publishedAt` 정의
- [ ] 앱은 draft/admin 콘텐츠를 제외한 published 카드만 읽음
- [ ] 이미지 앞면, 답 공개, 상세 WebView의 3단 흐름 구현
- [ ] 이미지와 마지막 성공 카드 묶음 캐시
- [ ] 원격 데이터 중복·결측·버전 하락 검증
- [ ] 원격 실패 시 내장 N5로 전환하고 사용자 학습 상태 유지
- [ ] 빌드 상수 없이 릴리스가 올바른 공개 endpoint를 찾는 설정 확정

완료 기준:

- 온라인/오프라인 모두 동일한 카드 ID와 진도를 유지한다.
- PenX 형식 오류 한 건이 전체 학습 화면을 중단시키지 않는다.
- WebView 오류가 이전/다음과 시험을 중단시키지 않는다.

### P2 — 유지율 엔진

목적: 사용자가 다음 날 다시 열 이유를 만든다.

- [ ] 카드 평가를 `모름 / 애매 / 암기`로 변경
- [ ] 틀린 카드의 당일 재노출
- [ ] 단순 SRS 복습 예정일 저장
- [ ] 오늘의 10자와 오답만 학습
- [ ] 7일 진도, 정답률, 연속 학습일
- [ ] 데이터 마이그레이션으로 기존 `암기 완료` 상태 보존

초기 제품 지표 목표(가설이며 실제 데이터로 조정):

- 첫 학습 세션 완료율 50% 이상
- 첫 시험 완료율 30% 이상
- D1 재방문 25% 이상
- D7 재방문 10% 이상

이 지표가 낮으면 과금 화면보다 온보딩·복습 루프를 먼저 수정한다.

### P3 — 시험 고도화

- [ ] 한자→뜻
- [ ] 뜻→한자
- [ ] 한자→음독/훈독
- [ ] 오답만 재시험
- [ ] N5 전체 모의시험
- [ ] 같은 뜻과 빈 읽기를 고려한 오답 선택지 품질 테스트

완료 기준: 문제 중복, 정답 복수 가능성, 빈 선택지 없이 고정 seed 테스트가
재현된다.

### P4 — 첫 수익화

권장 모델: **N5 무료 + Pro/급수팩 영구 구매**

무료 범위:

- N5 103자
- 기본 회상 학습
- 기본 10문제 시험
- 오프라인 fallback

유료 가치:

- 오답 집중과 SRS
- 상세 통계
- 추가 시험 유형
- N4 이후 급수팩
- 사용자 정의 세트(후속)

초기 가격 가설:

- 급수팩: 각 2,900~4,900원
- 초기 Pro 영구권: 5,900원
- N1~N5 전체 준비 후 전체 영구권: 9,900~12,900원

구독은 N1~N5, 지속 콘텐츠, 학습 계획, 클라우드 동기화와 모의시험이
갖춰진 뒤에만 검토한다. 배너/전면 광고는 사용하지 않는다. 광고 실험이
필요하면 사용자가 선택하는 보상형 추가 시험만 검토하고 Play 데이터 보안
신고를 먼저 갱신한다.

수익화 완료 기준:

- Play Billing 구매·취소·복원·오프라인 entitlement 테스트
- 구매하지 않아도 약속한 무료 N5 범위가 유지됨
- paywall 노출 이전에 사용자가 핵심 학습 가치를 경험함
- 결제 전환 2~4%를 초기 가설로 측정하되 유지율을 함께 봄

### P5 — 콘텐츠·유입 확장

- [ ] N4, N3 순으로 검수된 데이터와 시험 추가
- [ ] PenX `오늘의 한자` 공개 글에서 앱의 동일 카드로 딥링크
- [ ] 스토어 키워드와 스크린샷을 회상·쓰기 학습법에 맞춤
- [ ] 평점 요청은 여러 학습/시험 완료 후에만 표시
- [ ] N2/N1과 구독은 N4/N3의 유지율·구매 데이터를 본 뒤 판단

## 5. 측정 퍼널

수익 판단에 필요한 최소 퍼널:

```text
스토어 노출
  -> 설치
  -> 첫 카드 공개
  -> 첫 10자 완료
  -> 첫 시험 완료
  -> D1 / D7 복귀
  -> Pro 설명 확인
  -> 구매 시작
  -> 구매 완료 / 복원
```

분석 SDK를 넣기 전에는 Play Console 지표와 로컬 집계를 사용한다. 분석 SDK를
추가하면 개인정보처리방침과 Play 데이터 보안 신고를 함께 변경한다.

예시 단위 경제성(보장값 아님): 설치 10,000회, 결제율 2~4%, 가격 9,900원,
서비스 수수료 15% 가정 시 세금·환불 전 약 168만~337만원이다. 가격보다
유기적 설치와 D7 유지율이 먼저다.

## 6. 변경 순서 요약

```text
P0 보안·릴리스 신뢰성
  -> P1 카드/PenX 구조 정상화
  -> P2 오답·SRS·진도
  -> 무료 N5로 유지율 검증
  -> P3 시험 확장
  -> P4 N4+Pro 영구 구매
  -> P5 N3 이상과 지속 수익 실험
```

## 7. 하지 않을 것

- 유지율 검증 전에 구독부터 추가하지 않는다.
- 유료 가치를 만들기 전에 배너 광고로 학습 흐름을 훼손하지 않는다.
- 공식 JLPT 급수 목록이라고 표현하지 않는다.
- 공개 API에 관리자 초안이나 인증 정보를 노출하지 않는다.
- WebView 또는 AI를 크래시 원인으로 추측해 증거 없이 제거하지 않는다.
